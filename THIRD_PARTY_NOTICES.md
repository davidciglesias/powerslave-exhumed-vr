# Third-party notices

PowerSlave Exhumed VR is MIT licensed (see [LICENSE](LICENSE)). It is an unofficial fan mod, not affiliated with or
endorsed by Nightdive Studios, Lobotomy Software or Valve. It contains no files from the game: the install scripts
modify only the user's own installation (they rename the game's `SDL2.dll` and build the VR `kexengine.cfg` from the
game's own `default.cfg` on the user's machine).

| Project | Role | License |
|---|---|---|
| [MinHook](https://github.com/TsudaKageyu/minhook) by Tsuda Kageyu | Function hooking, statically linked into `SDL2.dll`. | BSD-2-Clause |
| [OpenXR SDK](https://github.com/KhronosGroup/OpenXR-SDK) by The Khronos Group | `openxr_loader.dll` (shipped unmodified in the release zip) and the OpenXR headers. | Apache-2.0 |
| [SDL2](https://github.com/libsdl-org/SDL) | Not included: the mod's `SDL2.dll` forwards every SDL call to the game's own copy (`SDL2_real.dll`). | zlib |
